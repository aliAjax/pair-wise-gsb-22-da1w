# hxwl-08 葡萄酒缺陷诊断训练台

盲品课用的缺陷诊断训练台：解决学员把**氧化、还原、软木塞污染**混成一类、讲师看不到下一步该补什么的问题。

## 技术栈

React + Vite + TypeScript + CSS，纯前端、数据全部存在浏览器本地。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5108

## 功能

- **开课前登记**：样酒编号、酒款描述、缺陷标签（答案，可多选）、讲师置信度、闻香线索（每行一条）。
- **同一场线索与答案分开**：训练中学员只看得到编号与闻香线索；答案、置信度、酒款名在提交判断前不可见，资料库答案默认收起、训练进行中强制遮蔽。
- **每轮 3–5 款**：训练开始前可在 3/4/5 之间切换；进行中的一轮使用题量快照，改题量只对下一轮生效。
- **自动排课**：优先到期的待复训样酒（按最早可复习日从早到晚），其次未练新酒，不足再用已掌握样酒维护抽测。
- **复习规则**：答错连对清零、归入待复训，并按「下一次训练日期」排入最早可复习日；同一款**连续答对两次**（门槛可调 2–4）才算掌握并出队。
- **暂停 / 关页面可续练**：已提交的判断写入只增留档，剩余题序、暂停状态和已判标记保存在进行中场次中，刷新或关掉页面再打开可接着练，且不会对当前款重复判题。
- **看板**：已掌握数、到期可复习数、待复训/未练数、近 30 次正确率与最常答错的缺陷标签；待复训队列表与留档列表（可导出 JSON）。

## 本地存储分区（localStorage，分键互不混用）

| 键 | 内容 |
| --- | --- |
| `defect-lab/v1/samples` | 训练资料：样酒、标签、置信度、闻香线索 |
| `defect-lab/v1/rules` | 复习规则：掌握连对数、下一次训练日期、每轮题量 |
| `defect-lab/v1/progress` | 每款样酒的连对、待复训状态与最早可复习日 |
| `defect-lab/v1/archive` | 本地留档：每次提交的判断（只增不改，可导出 JSON） |
| `defect-lab/v1/session` | 进行中场次：题序、已判标记、暂停状态 |
| `defect-lab/v1/tags` | 缺陷标签字典（首次使用内置：氧化、还原、软木塞污染等） |

首次打开会写入 8 条示范样酒（含干净对照样）。清除浏览器数据会同时清空资料与留档。

## 代码结构

- `src/types.ts` 领域模型
- `src/storage.ts` 五类分键本地存储
- `src/engine.ts` 组轮、判题、复习规则（纯函数，含断言测试）
- `src/seed.ts` 示范样酒
- `src/components/` 登记表单、资料库、规则面板、训练台、复习与留档面板
