# hxwl-08 葡萄酒盲品训练 · 缺陷诊断训练台

把氧化、还原、软木塞污染等易混淆缺陷拆成可训练、可复训的盲品流程。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5108

## 功能

- **讲师登记**：开课前录入样酒编号、缺陷标签、讲师置信度与闻香线索；线索与答案分开存放，学员提交判断前看不到标签
- **学员训练**：每轮 3–5 款样酒，只看线索提交缺陷判断，提交后揭晓标签与置信度
- **复习规则**：答错归入待复训，按下一次训练日期排入最早可复习日；同一款连续答对 2 次才算掌握
- **断点续练**：暂停、修改题量或关闭页面，已提交判断与剩余题序都保留，重开接着练
- **本地留档**：全部判断写入浏览器 localStorage，可导出 JSON、清空留档或重置全部数据

## 模块划分

- `src/data/materials.ts` — 训练资料（缺陷图鉴 + 预置样酒库）
- `src/domain/reviewRules.ts` — 复习规则（排期、掌握判定、组卷，纯函数）
- `src/storage/archive.ts` — 本地留档（localStorage 读写与兜底）
- `src/App.tsx` — 界面组装（学员训练 / 讲师登记 / 复训与留档）
